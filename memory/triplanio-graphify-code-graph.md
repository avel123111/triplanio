★PR в dev 2026-08-02: подключён **graphify** (github.com/Graphify-Labs/graphify, Apache-2.0/MIT) - локальный индексатор на tree-sitter, строит граф `узлы = файлы/функции/компоненты`, `рёбра = imports/calls/contains/references`. Парсит **на машине, без LLM и без единого токена**.

**Замер на нашем репо** (655 файлов кода, после `.graphifyignore` индексируется 516): сборка `--code-only` = **8 секунд**, 2024 узла / 6075 рёбер, `graph.json` 2.7 МБ. Доля рёбер `INFERRED` (догадка резолвера, а не факт из синтаксиса) - **0.7%**, то есть граф почти целиком детерминированный. Экономия контекста ~19× против чтения корпуса. С грамматикой SQL - 64 c и +454 узла схемы БД.

**Что сделано:**
- `.claude/commands/graph.md` - команда `/graph` (единственный НАДЁЖНО загружаемый канал в self-hosted Cyrus; `.claude/settings.json` в репо нет, значит хуков и автозапуска «на старте сессии» у нас нет).
- `.claude/skills/graphify/SKILL.md` - **наш** скилл, не вендоренная копия (запись в `VENDORED.md`): установка, три рабочие команды, границы доверия.
- `.graphifyignore` - `.claude/` (~90 узлов из чужих вендоренных скиллов), `dev/`, `src/lib/i18n/locales/` (0 узлов, 132 предупреждения).
- `.gitignore` += `graphify-out/`; `CLAUDE.md` - подпункт под rule #6 + строка-маршрут в rule #14.

**Три команды, которые работают:** `graphify affected "<символ>"` (blast radius с `file:line` = область регрессии), `graphify explain "<имя>"` (все связи символа), `graphify god-nodes` (несущие узлы; у нас `useI18n()` 150 рёбер, `useT()` 100, `useAuth()` 67, `invokeFn()` 57). **`graphify query` НЕ использовать** - это обход по совпадению названий, а не поиск по смыслу (на «pro subscription gating» приносит `useTheme()`).

**Где граф точен:** файловый уровень импортов сверен с грепом и сходится - `Btn` 35 против 34 файлов, `Badge` 11/11, `Skeleton` 15/15, `Field` 5/5, `Card` 1/1. Такой ответ можно ставить в строку `Reuse audit:`.

★★**Граф НЕ авторитет по мёртвому коду - главное ограничение.** Он видит только статические связи внутри JS/TS; всё, что связано строкой, классом или ключом, для него не существует. Замерено: **199 символов** в `src/**` «без входящих ссылок», из проверенных живы ВСЕ (`Msg` ChatStream.jsx:155, `HotelBody` EventViewBody.jsx:917, `SidebarBody` TripSidebar.jsx:126, `brandSvg` icons.jsx - 5 вызовов) - использование JSX внутри своего файла рёбер не создаёт; **43 из 45 edge-функций** выглядят осиротевшими, потому что зовутся строкой `invokeFn('copyTrip')`; CSS-классы и i18n-ключи не индексируются вовсе; ребра `.rpc('create_trip')` → SQL-функция нет (SQL-слой, даже с грамматикой, остаётся изолированным островом). Правило: граф даёт **кандидата**, мёртвость подтверждается ручным проходом по шести источникам - `src/**`, `supabase/functions/**`, `supabase/migrations/**`, `locales/**`, `*.css`, воркфлоу n8n. Цена пропуска - [[feedback-dead-i18n-key-sweep-must-scan-backend]].

**Чего он не закрывает:** главную проблему переиспользования [[triplanio-design-unification-trip321]] (261 CSS-префикс, 4600 стилевых объявлений) - `.css` он не парсит вообще; и неиспользуемые экспорты фронта (нужен профильный инструмент вроде `knip` = новая зависимость, отдельный апрув).

**Осознанные решения:**
- **Граф не коммитится.** Собирается заново каждую сессию за 10 c. 3 МБ в каждом PR + конфликты (upstream даже возит merge-driver под это), а главное - устаревшая карта хуже отсутствующей, ей поверят.
- **Их инсталлятор (`graphify install` / `graphify claude install`) не запускаем**: пишет в `~/.claude` (эфемерный контейнер, урок TRIP-23), дописывает свою секцию в наш `CLAUDE.md` и вешает PreToolUse-хук, в строгом режиме запрещающий читать файлы до запроса к графу - чужой инструмент начинает командовать нашими правилами.
- **MCP-сервер не подключаем**: у нас уже 5 серверов, а его серверу нужен готовый `graph.json` в момент старта сессии - на свежем клоне его нет.
- **Грамматика SQL по умолчанию не ставится**: +58 c к сборке ради изолированного острова. Ставится точечно: `uv tool install "graphifyy[sql]"`.

**Грабли окружения:** после `uv tool install` бинарь **не в PATH** - нужен `export PATH="$HOME/.local/bin:$PATH"`. Установка живёт только внутри сессии. И поправка к [[triplanio-agent-connectors]]: **python3 в окружении ЕСТЬ** (3.11.15) вместе с `uv` 0.8.17 - прежняя запись «нет python3» устарела.
