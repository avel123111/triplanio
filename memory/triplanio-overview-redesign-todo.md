**Виджет «Подготовка» (контракт):**
- Слоты: отель на КАЖДЫЙ город (city_visit кроме транзита) + переезд на КАЖДЫЙ стык соседних городов (N−1). «Забронировано» = сущность СУЩЕСТВУЕТ (hotel_stay для города / transfer для стыка) — `is_booked` в модели ПО-ПРЕЖНЕМУ НЕТ ([[triplanio-booked-flag-plan-fact]], код не начат; после его внедрения появится третье состояние «есть, но не подтверждено»).
- Состав: шапка-канон `.wdg-h` + бейдж `N/M`; прогресс (бар-пилюля 11px по форме `.bud-bar` ИЛИ кольцо-канон `.wring`); счётчики-чипы «Отели h/H» · «Переезды t/T» (тоны `--ev-hotel`/`--ev-transfer`); список слотов: занятый = `ListRow variant="raised"` (тайл типа + галка success + chevron) → клик открывает СУЩЕСТВУЮЩУЮ left panel просмотра (EventDrawerHost); пустой = `ListRow variant="add"` (пунктир, `--a` тон типа) → клик открывает СУЩЕСТВУЮЩУЮ fork-панель отелей (manual CTA + Stay22) / панель создания переезда. Done-state (всё забронировано) = success-плашка; empty-state (нет городов) = EmptyState с CTA «Открыть маршрут».
- На мобиле панели = bottom sheet (канон `.lp-sheet`), прогресс-бар вместо кольца где узко.
