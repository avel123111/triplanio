# ИИ-планировщик: драфт → операции (TRIP-527)

**Как работает.** Фронт (`ManualPlanner`) хранит черновик маршрута (`nodes`,
`startDate`, `tripTitle`) и каждой репликой шлёт его в `planTripWithAi` как
`draft` (`routeModel.toDraftPayload`: `ref = String(node.id)`, kind, имена,
country_code, nights, geonameid; ряды без города не едут). Edge проверяет только
ФОРМУ и размер (`planTripWithAi/draft.ts`: объект|null, ≤60 узлов, строки ≤200,
лишние поля срезаются, нарушение = 400) и пробрасывает в n8n **`AI Trip Planner
v2`** (`mnLYKZCMpvepHwag`, путь `ai-trip-planner-v2`). Модель отвечает
`{ai_comment, ops}`; `ops` может быть пустым — разговор без правок законен.
Применяет операции чистый `src/pages/create/aiOps.js` (`applyOps`) поверх
`routeModel`; результат — новые `nodes/startDate/title` + `applied[]` и
`rejected[]` (битая операция пропускается и сообщается, соседние применяются).
Лимит 50 реплик/час на пользователя.

**Словарь операций — ОДИН источник (`OPS` в `aiOps.js`).** `set_route` (только
на драфте без городов), `add_city`, `replace_city` (место, id и ночи сохраняются),
`remove_city`, `move_city`, `set_nights` (0 = пересадка), `set_start`, `set_end`,
`clear_end`, `set_start_date`, `set_title`. Из словаря выводятся `opsJsonSchema()`
(кладётся в Structured Output Parser n8n как есть) и `opsPromptLines()` (строки
системного промпта). Полная смена маршрута при непустом драфте = `remove_city`
на каждый ref, затем `set_route` — операции применяются по порядку.

**Драфт на edge** (`planTripWithAi/draft.ts`): `normalizeDraft` отдаёт либо
`Refusal` шва записи, либо `{ draft }` (`null` — первая реплика без черновика);
вызыватель различает исходы той же проверкой `'status' in r`, что `mutate.ts`,
своего предиката нет. `country_code` — ISO alpha-2 (кэп 2).

**Ловушки.**
- ★ **Одно имя на один смысл.** Поля всех операций лежат в схеме парсера плоско,
  и модель выбирает имя по смыслу, а не по операции: пока дата у `set_route`
  звалась `startDate`, а у `set_start_date` — `date`, прогон дал
  `set_start_date {startDate}` (2 из 2). Поэтому дата везде `startDate`, город
  везде `city_name…`, узел везде `ref`; тест пинит отсутствие второго имени.
- **Города из операций резолвит ВЫЗЫВАТЕЛЬ** одним батчем газеттира
  (`citiesInOps(ops)` → `resolveCities` → `applyOps({cities})`); порядок обхода
  у обеих функций один и запинен тестом (курсор двигается и через отказанный
  `set_route`). Нерезолвленный город добавляется без координат и краснеет на
  шаге 2, как ручной ввод.
- **Состояние для применения — из рефа**, не из замыкания `onSuccess`
  (`draftRef`): `useMutation` зовёт колбэк с опциями рендера, где вызвали
  `mutate`, а операции применяются к тому, что на экране сейчас.
- **Маршрут в ленте ОДИН и живой** (`PanelAi` рисует `DraftItinerary` от
  `nodes` ПОД ЛЕНТОЙ, после последнего сообщения). Снимок маршрута в каждом
  сообщении бота снят: после операций он врал бы. В сообщении — только текст
  бота. Ряд маршрута СВОЙ, не ряд шага 2 (решение Pavel): слева номер (у
  старта/финиша плитка-флажок в AI-тоне), название города и под ним флаг со
  страной, справа даты и число ночей (у якорей дата и «Старт»/«Финиш»);
  собран из `Row`/`Col` ДС и носителей `te-row__num`/`te-cityname`, своих
  классов нет. Номер у города ОДИН на все поверхности — `visitNumberOf`
  (`routeModel`): считаются только города посещения, пересадка и якоря номера
  не получают, как у пинов карты (`cityPoints`); шаг 2 и ряд под лентой зовут
  его же. Пересадка — плитка `tone="transfer"` в `te-row__node` (правило
  `.te-row__node.tile--transfer`, пунктир; инлайна нет ни в одном из трёх
  мест: шаг 2, лента ИИ, `EditLens`). Даты — `tripDates.cityDateRange` →
  `shortDateLabel` = канон `dayMonth` (день-первый во всех локалях; своя
  `Intl`-копия с обратным порядком в en снята), арифметика — luxon `toDT`.
  Число ночей/городов — `pluralize`, не тернарии `n < 5`.
  ★Отвергнуто Pavel и не возвращать: маршрут ОТДЕЛЬНЫМ экраном
  от чата (док «последняя реплика + переключатель», вкладки, две области с
  независимой прокруткой над композером) — «никто никогда не разберётся»,
  на среднем детенте шита областям остаётся 400 px на двоих.
- **Строк «сделал / не смог» под текстом бота НЕТ** (семья `ai_plan.did_*`/
  `fail_*` удалена из локалей, Tolgee и `PROTECTED_KEYS` 2x): бот про валидатор
  не знает, и «не смог» под его «сделал» — противоречие. Отказ применятора —
  телеметрия вызывателя: PostHog `ai_ops_rejected` + Sentry с причинами; на
  прогоне 19 реплик отказов 0.
- **n8n не версионируется**: v2 собран кодом SDK через MCP, схема и промпт
  скопированы из репо; дрейф репо↔n8n машинно не проверяется — при смене `OPS`
  перегенерировать схему/строки и обновить узлы `Structured Output Parser` и
  `AI Agent`. v1 (`U9nM2nTiIkYk6g9O`, путь `ai-trip-planner`) живёт, пока
  прод-фронт с полной заменой не уехал; после мерджа в `main` — в архив.
- **Приветствие на пустом драфте больше не выдумывает маршрут** (v1 отдавал
  Прагу-Вену на «приветики»); прогон v2 на 13 сценариях из реальной истории
  (`ai_planning_requests`, data-table n8n) — операции с верными `ref`, честная
  фраза про отели/перелёты, совет текстом без операций.
- Сброс на AI-шаге: футер там занят композером, кнопка — `IconBtn` в шапке
  панели на ту же `requestReset` (новая сессия памяти n8n + снос черновика).
- Стенд визуальной проверки — НАСТОЯЩИЙ `ManualPlanner` (в репо не лежит,
  каталог `.stand/` под локальным `.git/info/exclude`): свой `vite.config.mjs`
  без html-плагинов прод-сборки (splash/prerender роняют чужой html), алиасы
  точнее `@` подменяют сетевые двери стабами (`AuthContext`, `invokeFn` со
  сценариями ответа бота по тексту реплики, `useActiveTripsLimit`, `analytics`,
  `sentry`, `geo`), HTML-точка с провайдерами Theme/I18n/QueryClient/Confirm/
  Map + `MemoryRouter`, планировщик ВНУТРИ `<Route element={<TripShell/>}>`
  (с TRIP-520 экрану нужен `ShellSlot`); env `VITE_SUPABASE_*`/
  `VITE_TRIPLANIO_BOT_USER_ID` через окружение процесса; `playwright-core` из
  `node_modules` репо, контекст телефона `isMobile+hasTouch`, `locale:'ru-RU'`.
  ★Снимать на ДЕФОЛТНОМ детенте, не поднимать шит тапом по грипу — иначе кадр
  врёт про экран (уже стоило круга правок). Токена mapbox нет — карта пустая.
