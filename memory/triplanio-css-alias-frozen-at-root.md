# Triplanio: алиас, объявленный в `:root`, вычисляется НА `:root` (TRIP-341 / TRIP-352)

**Правило (голая механика CSS):** `--X: var(--Y)` в `:root` — это НЕ ссылка, которая
разрешается у каждого потомка. Подстановка `var()` в значении кастомного свойства
происходит при вычислении значения **на том элементе, где стоит объявление**, то
есть на `:root`. Потомки наследуют уже ПОДСТАВЛЕННОЕ значение. Поэтому
переопределение `--Y` на потомке **`--X` не трогает**.

```css
:root  { --brand-soft: rgba(33,115,200,.10);
         --hl-soft: var(--brand-soft); }   /* вычислено ЗДЕСЬ = rgba(33,115,200,.10) */
.auth  { --brand-soft: rgba(33,103,226,.08); }   /* --hl-soft под .auth НЕ поменялся */
```

## Почему это стоит отдельной заметки

Заметку уже теряли один раз: агент TRIP-352 отчитался, что записал её, а файла в
`dev` не оказалось (PR #699 нёс только `app.css`) — Pavel заказал восстановление
в TRIP-341 PR 3. Причина, по которой её вообще написали: **из-за этого механизма
стенд в TRIP-352 показывал ЛОЖНЫЕ значения.** На стенде переопределяли токен-цель
на контейнере и мерили алиас — он «не реагировал», и это читалось как сломанный
стенд, а не как правильное поведение браузера. Вывод чуть не уехал в тред как
доказательство.

## Где это кусает в этом репо

* **Токенные острова.** `login.css .auth` и `PublicTrip.css .ptrip` пиннят свои
  значения на потомке. Любой алиас из `:root` (`--hl-soft: var(--brand-soft)`,
  `--accent: var(--brand-soft)`, `--r-control: var(--r-btn)`) внутри острова
  держит значение `:root`, а не острова. Это **известная незакрытая дверь**, а не
  баг конкретного PR — периметр островов закрывается в подзадаче 10 эпика
  [[triplanio-design-unification-trip321]].
* **Зеркальная ловушка при рефакторинге** описана в шапке
  `scripts/ci/audit-design.mjs` (секция ALIASES) с другой стороны: подставить
  `var(--Y)` вместо `var(--X)` в КОДЕ — не эквивалентная замена, если `--Y`
  переопределён на потомке. Тот же факт, вид со стороны правки.
* **Тема — НЕ этот случай.** `:root` и `:root[data-theme=dark]` матчат ОДИН И ТОТ
  ЖЕ элемент, поэтому `--X` и `--Y` там пересчитываются вместе. Расщепить алиас
  может только объявление на ПОТОМКЕ (`.auth`, `.btn`, `.tmk--finish`).

## Следствие, на котором стоит канон тинта

Ровно из этого следует, почему в TRIP-341 PR 3 у читателей канала `--hl*` **нет
фолбэков**: имя объявлено в `:root`, значит первый аргумент `var()` определён
ВСЕГДА, и второй не сработает никогда. Оставленный фолбэк вида
`var(--hl-soft, var(--brand-soft))` — мёртвый код, которого **не видит ни один
гард**: 2p сравнивает текст объявления, а мёртвую ветку `var()` не исполняет
никто. Обратная сторона той же монеты: пока ручку ставили инлайном
(`--ev-soft` нигде не объявлена), фолбэк работал — и переезд на объявленное в
`:root` имя молча менял значение. Это и была ловушка, ради которой #699 выравнивал
альфу ЗАРАНЕЕ.
