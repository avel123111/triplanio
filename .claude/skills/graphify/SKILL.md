# graphify — граф кода проекта

Локальный индексатор на tree-sitter. Парсит код **на машине, без LLM и без
единого токена**, строит граф `узлы = файлы/функции/компоненты`,
`рёбра = imports / calls / contains / references`. Сборка всего репо — ~8 секунд.

Быстрый путь: команда `/graph` собирает граф и даёт ориентировку. Этот файл —
для ручной работы и для понимания, чему в графе можно верить.

## Установка и сборка

Контейнер сессии эфемерный, поэтому ставить нужно один раз за сессию:

```bash
uv tool install graphifyy          # ставит graphify в ~/.local/bin
export PATH="$HOME/.local/bin:$PATH"   # обязательно: по умолчанию его нет в PATH
graphify extract . --code-only     # ~8 c → ./graphify-out/graph.json
```

`graphify-out/` в `.gitignore` — граф в репозиторий не коммитится **никогда**.
Он собирается заново, потому что устаревшая карта хуже отсутствующей: агент ей
поверит. Пересобрать после своих правок — `graphify extract . --code-only`
(инкрементально, только изменённые файлы).

Опция `--code-only` обязательна: без неё инструмент полезет разбирать картинки
и PDF через LLM-бэкенд.

## Три команды, которые реально работают

```bash
graphify affected "useProStatus"     # blast radius: кого заденет правка, с file:line
graphify explain  "Btn"              # все связи символа: кто зовёт, кого зовёт
graphify god-nodes --top 12          # несущие узлы проекта = карта архитектуры
```

`affected` и `explain` — основные. Оба дают путь и номер строки, то есть ответ
можно сразу проверить глазами, а не принимать на веру.

`graphify query "…"` — **не использовать**. Это обход графа по совпадению
названий, а не семантический поиск: на запрос «pro subscription gating» он
приносит `useTheme()`. Для поиска по смыслу остаётся обычный grep.

## Границы доверия — читать до того, как что-то удалять

Граф видит **статические связи внутри JS/TS**. Всё, что связано строкой,
классом или ключом, он не видит вовсе. Замерено на нашем репозитории:

| Что | Что говорит граф | Как на самом деле |
|---|---|---|
| Локальные JSX-компоненты (`<Msg />` внутри своего файла) | 199 символов «без входящих ссылок» | проверенные — все живые; использование JSX рёбер не создаёт |
| Edge-функции (`invokeFn('copyTrip')`) | 43 из 45 «без входящих» | все живые, зовутся строкой |
| CSS-классы | не индексируются | 1334 класса вне графа |
| i18n-ключи | не индексируются | ключи живут ещё и в БД, edge-функциях, миграциях |
| `.rpc('create_trip')` → SQL-функция | ребра нет | связь есть |

Отсюда единственное правило: **«в графе нет входящих ссылок» не значит
«мёртвое»**. Граф выдаёт кандидата; мёртвость подтверждается вручную по шести
источникам — `src/**`, `supabase/functions/**`, `supabase/migrations/**`,
`src/lib/i18n/locales/**`, `*.css` и воркфлоу n8n. Три из шести граф не видит в принципе.
Цена ошибки описана в `memory/feedback-dead-i18n-key-sweep-must-scan-backend.md`:
снесли 606 «мёртвых» ключей по скану одного `src/**` — 104 строки на проде
отрендерили сырой ключ.

Отдельно про i18n: локали лежат **не в корне**, а в `src/lib/i18n/locales/`
(132 файла `en/es/ru`) — путь `locales/**` не существует, скан по нему вернёт
пусто и будет прочитан как «ссылок нет». И репозиторий там не единственный
источник: при `pull` авторитет — Tolgee, поэтому ключ удаляется в ОБОИХ местах,
а его отсутствие в repo JSON само по себе ничего не доказывает
(`memory/feedback-new-i18n-keys-go-to-tolgee.md`).

## Где граф точен

Файловый уровень импортов сверен с грепом и сходится: `Btn` 35 против 34
файлов, `Badge` 11/11, `Skeleton` 15/15, `Field` 5/5, `Card` 1/1. Доля рёбер
`INFERRED` (догадка резолвера, а не факт из синтаксиса) — 0.7%. То есть
«кто импортирует этот компонент» и «кого заденет правка этого хука» — ответы
надёжные, и их можно ставить в строку `Reuse audit:`.

## Опциональное

```bash
uv tool install "graphifyy[sql]"   # +454 узла схемы БД: таблицы, функции, триггеры
```

Удорожает сборку с 8 до 64 секунд и остаётся изолированным островом — с
TypeScript-кодом узлы БД не связаны. Ставить точечно, когда нужна карта схемы.

Их собственную интеграцию (`graphify install`, `graphify claude install`) **не
запускать**: она пишет в `~/.claude` (эфемерно, до следующей сессии не доживёт),
дописывает свою секцию в наш `CLAUDE.md` и вешает хук, который в строгом режиме
запрещает читать файлы, пока не сходишь в граф.
